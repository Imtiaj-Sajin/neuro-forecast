Download these two files from the Hugging Face organisation BrainGPT and place them in this folder.

| File | Source | Rows | Licence |
|---|---|---|---|
| BrainBench_Human_v0.1.csv | https://huggingface.co/datasets/BrainGPT/BrainBench_Human_v0.1.csv | 200 | Apache-2.0 |
| BrainBench_GPT-4_v0.1.csv | https://huggingface.co/datasets/BrainGPT/BrainBench_GPT-4_v0.1.csv | 100 | not stated on the dataset card |

Columns in both files: doi, journal_section, original_abstract, incorrect_abstract.

The CSV files are not committed to this repository (see .gitignore).
